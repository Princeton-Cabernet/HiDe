# HiDe
Code repository for our NINeS 2026 paper titled "Passive Data-Plane Telemetry to Mitigate Long-Distance BGP Hijacks".

<b>countries_analysis:</b> Code to analyze distances and optimal attacks across countries in the Natural Earth dataset.

<b>notebooks:</b> Code to analyze the MLab and campus datasets, and to evaluate HiDe.

<b>hardware_prototype:</b> Code to run the hardware prototype of HiDe on an Intel Tofino programmable switch.
